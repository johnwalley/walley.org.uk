Visualising the distribution of data is something that crops up frequently. This [blog post](https://www.darkhorseanalytics.com/blog/visualizing-distributions-3) by Dark Horse Analytics does a good job summarising a few of the options available.

I particularly like the rough hand-drawn effect used for the examples. Here's a bar-code chart. Just a simple line plotted for every point.

<Image src={distribution1} alt="" />

I've also been looking for an opportunity to try out [RoughJS](http://roughjs.com/). A small Javascript library that lets you draw in a sketchy, hand-drawn-like, style.

You can probably see where this is going! Here are the results of mixing a little d3 with RoughJS. I'm pleased with the results. The first chart is a bar-code chart. The second is a bee swarm chart. The points are spread out to avoid overlap. This makes it easier to see individual points but can get out of hand for large numbers of points!

<Image
  src={distributions}
  alt="A hand-drawn style bar-code chart and bee swarm chart of the same finish times, which cluster between 21 and 24 minutes."
/>

Both charts show the same data (finish times for a rowing race). The source code is also [available](https://gist.github.com/johnwalley/595596f5403acb1cd2da49ad8fa1e8df/0be1a8f01e5dddd4ef81434981d3c4b8e126faf2).
